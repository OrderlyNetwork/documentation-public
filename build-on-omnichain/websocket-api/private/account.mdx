```json

  "id": "clientID3",
  "topic": "account",
  "event": "subscribe"
```

**Parameters**

| Name  | Type   | Required | Description               |
| ----- | ------ | -------- | ------------------------- |
| id    | string | Y        | id generate by client     |
| event | string | Y        | `subscribe`/`unsubscribe` |
| topic | string | Y        | `account`                 |

## Orderly Predict

`accountDetail` additively includes `binaryMakerFeeRate` and `binaryTakerFeeRate` (in bps), with the same meaning, unit, and value as the matching fields on `GET /v1/client/info`.

If the account's Predict fee rates cannot be resolved for a given push, both fields are omitted from that push rather than sent as `0`; other `accountDetail` fields are unaffected. A missing `binaryTakerFeeRate` does not mean the account trades Predict for free -- do not default an omitted rate to `0`. See [Positions and Settlement](/build-on-omnichain/orderly-predict/positions-and-settlement#fees) for how these rates are used.
