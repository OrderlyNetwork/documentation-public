---
title: "bbo"
description: "Subscribe to best bid and offer (BBO) updates for a single symbol via WebSocket, pushed every 10ms."
---

Push interval: 10ms

```json
{
  "id": "clientID5",
  "topic": "PERP_WOO_USDC@bbo",
  "event": "subscribe"
}
```

**Parameters**

| Name  | Type   | Required | Description               |
| ----- | ------ | -------- | ------------------------- |
| id    | string | Y        | id generate by client     |
| event | string | Y        | `subscribe`/`unsubscribe` |
| topic | string | Y        | `{symbol}@bbo`            |

<RequestExample>

```json Response
{
  "id": "clientID5",
  "event": "subscribe",
  "success": true,
  "ts": 1609924478533
}
```

</RequestExample>

<ResponseExample>

```json Subscribed Message
{
  "topic": "PERP_WOO_USDC@bbo",
  "ts": 1614152296945,
  "data": {
    "symbol": "PERP_WOO_USDC",
    "ask": 0.30939,
    "askSize": 4508.53,
    "bid": 0.30776,
    "bidSize": 25246.14
  }
}
```

</ResponseExample>

## Orderly Predict

For a Predict round symbol (`<binary_symbol>`), the push additionally includes `down_bid` and `down_ask`. `bid` and `ask` keep their existing UP-side semantics. `down_bid = 1 - ask` and `down_ask = 1 - bid`.

```json Subscribed Message
{
  "topic": "<binary_symbol>@bbo",
  "ts": 1614152296945,
  "data": {
    "symbol": "<binary_symbol>",
    "ask": 0.56,
    "askSize": 120,
    "bid": 0.55,
    "bidSize": 100,
    "down_bid": 0.44,
    "down_ask": 0.45
  }
}
```

Non-Predict symbols do not return `down_bid` or `down_ask`. See [Market Data](/build-on-omnichain/orderly-predict/market-data#order-book) for how the UP and DOWN sides relate.
