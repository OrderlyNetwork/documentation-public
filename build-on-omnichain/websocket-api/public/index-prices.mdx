---
title: "Index prices"
description: "Subscribe to index price updates for all symbols via WebSocket, pushed every second."
---

Push interval: 1s

```json
{
  "id": "clientID7",
  "topic": "indexprices",
  "event": "subscribe"
}
```

**Parameters**

| Name  | Type   | Required | Description               |
| ----- | ------ | -------- | ------------------------- |
| id    | string | Y        | id generate by client     |
| event | string | Y        | `subscribe`/`unsubscribe` |
| topic | string | Y        | `indexprices`             |

<RequestExample>

```json Response
{
  "id": "clientID7",
  "event": "subscribe",
  "success": true,
  "ts": 1682241351985
}
```

</RequestExample>

## Orderly Predict

`indexprices` includes the Predict Index row, identified by `symbol: "SPOT_BTCTWAP60S_USDC"`. This is the rolling 60-second TWAP of Orderly's BTC index price, updated every second. The underlying BTC row (`SPOT_BTC_USDC`) is also included and is unchanged.

Rows for a Predict round's own valuation index are excluded. See [Predict Index](/build-on-omnichain/orderly-predict/market-data#predict-index) for the calculation, settlement boundaries, and history access; subscribe to [the single-symbol topic](/build-on-omnichain/websocket-api/public/index-price#orderly-predict) if you only need Predict Index updates.
